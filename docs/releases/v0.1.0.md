QuietDrop is a local-first file intake and staging tool: it watches folders, queues new files for review, and archives, renames, tags or rejects them only when you say so.

**Pre-release.** First tagged release of a working project. An engineering tool for demonstration and controlled local use.

### What it does
- CLI: `init`, watch and one-shot scan, review queue, archive, reject, rename, tag.
- A local web UI and JSON API (bound to localhost) over the same queue.
- SQLite storage; nothing is moved or renamed without an explicit action.

### Verified
- 14 automated tests pass in CI, covering intake, archive, rename and file-operation safety.
- The wheel installs in a clean environment and the `quietdrop` command runs.

### Known limits
- Working MVP: richer review metadata, screenshots and service-style deployment examples are not done.
- Watcher and web behaviour have limited test coverage.
- Not tested on Windows or macOS by hand.

Checksums are in `SHA256SUMS`. See the [changelog](https://github.com/5K-bit/QuietDrop/blob/v0.1.0/CHANGELOG.md) for details.
